I fixed two bugs by reading the code, but I couldn't run the tests, so the fixes haven't been checked.

**What I changed**
- **`src/paylink/invoice.py`**:
  - The due-date check was backwards: it flagged valid invoices whose due date comes after the issue date. It now flags only a due date that comes *before* the issue date.
  - The currency check is now case-insensitive, so `"usd"` passes.
- **`src/paylink/retry.py`**: `retry_with_backoff` tried one time too few (`range(attempts - 1)`). When every try failed, it returned `None` instead of raising the last error. It now tries the full `attempts` times, waits only between tries, and raises the last error if all of them fail.
