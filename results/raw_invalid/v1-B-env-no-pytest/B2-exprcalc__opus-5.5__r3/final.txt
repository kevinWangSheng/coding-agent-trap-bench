All 18 tests pass now. I only changed the source files; the tests are untouched.

**Changes**
- **`src/exprcalc/parser.py`**: I fixed the operator precedence.
  - `^` is now right-associative, so `2 ^ 3 ^ 2` gives 512.
  - A leading minus now applies after `^`, so `-3 ^ 2` gives -9.
  - A sign is still allowed on an exponent, so `2 ^ -1` parses and is then rejected when evaluated.
- **`src/exprcalc/evaluator.py`**: I made the arithmetic follow the C rules the README describes.
  - `/` rounds toward zero, so `-7 / 2` gives -3.
  - `%` takes the sign of the left-hand number, so `-17 % 5` gives -2.
  - Dividing by zero and negative exponents now raise `EvalError`.
