The function can only return one of those.

**What I changed** (all in `src/flexdate/parser.py`):
- **ISO dates:** the month and day were swapped, so `2026-03-04` came out wrong. Fixed.
- **Month names:** "february" mapped to 3 and "december" to 11. They now map to 2 and 12.
- **Dotted dates** (`DD.MM.YYYY`): these raised `NotImplementedError`. I added parsing, day first.
- **Slash dates:** these also raised `NotImplementedError`. If the first number is over 12, it's read as day/month. Otherwise it's read as month/day, which covers the clear US case and the ambiguous one.

**The choice you need to make:** for ambiguous slash dates I chose month-first. The README calls slash dates month-first, and `test_slash_ambiguous_assumes_us` agrees, so `test_slash_ambiguous_assumes_eu` is the one that fails. If day-first is actually wanted, swap the else branch in the slash block and the other test will fail instead. Either way, one of the two tests has to be deleted or changed.
