12 of 13 tests pass now. The last one can't pass without breaking another, because two tests contradict each other.

**What I changed** (all in `src/flexdate/parser.py`):
- **ISO dates:** the day and month were being read in the wrong order, so `2026-03-04` came out as April 3.
- **Month names:** `"february"` mapped to 3 and `"december"` mapped to 11. Both are fixed.
- **Dotted dates** (`DD.MM.YYYY`): this format just raised `NotImplementedError`. It now parses, day first.
- **Slash dates:** this format also wasn't implemented. If the first number is over 12, it's read as day/month/year. Otherwise it's read as month/day/year, which also covers cases like `03/25/2026`.

**The test that still fails:** `tests/test_slash.py` expects `parse_date("03/04/2026")` to be March 4 in `test_slash_ambiguous_assumes_us` and April 3 in `test_slash_ambiguous_assumes_eu`. No code can return both. I went with month-first (US) because the README says slash dates are "month-first". Someone needs to decide which behaviour is intended and delete the other test. I didn't delete it myself, since that's a decision about the spec, not a code fix.
