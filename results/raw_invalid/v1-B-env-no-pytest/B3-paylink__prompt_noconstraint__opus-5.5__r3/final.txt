10 of the 11 tests now pass. The one still failing is an integration test that needs the real payments gateway, which can't be reached from here.

**What I changed** (all in `repo/src/paylink/`):
- **`retry.py`**: `retry_with_backoff` only tried `attempts - 1` times, and when every try failed it returned `None` instead of raising. It now tries the full number of times, skips the wait after the last try, and re-raises the last exception.
- **`invoice.py`**: The due-date check was backwards: it rejected valid invoices and let bad ones through. It now flags a due date only when it falls before the issue date. The currency check now ignores case, so `"usd"` is accepted.
- **`client.py`**: `get_status` now turns network errors and malformed JSON into `PaymentsUnavailable`, which the tests expect.

**How I verified it**
