Implemented a SQLite multi statement preparation optimization in [virtual.rs](~/.bench-runs/D-sqlx__gpt-6-astra__r2/repo/sqlx-sqlite/src/statement/virtual.rs).

- SQLite now prepares each statement using only its own SQL slice, avoiding repeated scans of the remaining script.
- Trigger statements retain the existing full parser behavior.
- Added focused unit tests.

- 4,000 statements: 634.5 ms → 14.2 ms
- 16,000 statements: 4.0 s → 75.7 ms
